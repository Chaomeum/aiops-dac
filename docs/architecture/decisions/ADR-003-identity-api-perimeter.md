Title: Use Microsoft Entra ID and Azure API Management for identity and API perimeter
Status: Accepted
Date: 2026-10-03

## Decision

Usar Microsoft Entra ID para identidad, autenticación y autorización corporativa,
y Azure API Management como perímetro de exposición y protección de APIs.

La decisión se registra en `access_and_governance_controls` y en
`deployment.identity_and_api_perimeter`, y cierra exclusivamente
OQ-006 — identity_and_api_perimeter.

## Rationale

Integración nativa con Azure, control de acceso corporativo, mínimo privilegio
y protección centralizada de APIs.
